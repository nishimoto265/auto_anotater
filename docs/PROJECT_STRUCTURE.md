# 🏗️ プロジェクト構造ガイド

## 📖 はじめに

このドキュメントは、**高速オートアノテーションシステム（Fast Auto-Annotation System）**のプロジェクト構造を理解するための完全ガイドです。初めてこのプロジェクトに触れる方でも、どのファイルがどこにあり、何をしているのかが分かるように詳しく説明しています。

## 🎯 プロジェクトの概要

### 目的
個人用の動物行動解析向け半自動アノテーションツール。4K動画から5fpsでフレームを抽出し、最大16個体の動物に対してバウンディングボックス（BB）でアノテーションを行います。

### 主な特徴
- 🖥️ PyQt6ベースのデスクトップアプリケーション
- ⚡ フレーム切り替え50ms以下の高速処理
- 🐾 最大16個体の動物追跡対応
- 🎯 YOLO形式でのアノテーション出力
- 💾 64GBメモリを活用した高速キャッシュ

## 🗂️ 各ディレクトリの詳細説明

### 1. src/ - ソースコード

アプリケーションの実際のコードが格納されています。8つの層（レイヤー）に分かれており、それぞれが特定の責任を持っています：

#### 🎨 presentation/ - プレゼンテーション層
- **役割**: ユーザーインターフェース（UI）を担当
- **主な機能**: 画面表示、マウス・キーボード操作の処理、BB描画
- **重要ファイル**: 
  - `main_window/main_window.py`: メインウィンドウ
  - `bb_canvas/bb_canvas.py`: BB描画キャンバス

#### 🔧 application/ - アプリケーション層
- **役割**: ビジネスロジックの統合と制御
- **主な機能**: ワークフロー管理、サービスの呼び出し、データ検証
- **重要ファイル**:
  - `services/annotation_service.py`: アノテーション管理
  - `controllers/frame_controller.py`: フレーム切り替え制御

#### 💼 domain/ - ドメイン層
- **役割**: ビジネスルールとエンティティの定義
- **主な機能**: BB管理、IOU計算、追跡アルゴリズム
- **重要ファイル**:
  - `entities/bounding_box.py`: BBエンティティ
  - `algorithms/iou_calculator.py`: IOU計算

#### ⚙️ infrastructure/ - インフラストラクチャ層
- **役割**: 技術的な基盤処理
- **主な機能**: 動画処理、画像変換、システムリソース管理
- **重要ファイル**:
  - `video/video_loader.py`: 動画読み込み
  - `video/frame_extractor.py`: フレーム抽出

#### ⚡ cache_layer/ - キャッシュ層（最重要）
- **役割**: 高速フレーム切り替えを実現
- **主な機能**: LRUキャッシュ、フレーム先読み、メモリ最適化
- **重要ファイル**:
  - `frame_cache/lru_frame_cache.py`: 高速キャッシュ実装

#### 📡 data_bus/ - データバス層
- **役割**: 層間の通信を管理
- **主な機能**: イベント配信、メッセージング、API提供
- **重要ファイル**:
  - `event_bus/event_dispatcher.py`: イベント配信システム

#### 💾 persistence/ - 永続化層
- **役割**: データの保存と読み込み
- **主な機能**: YOLO形式出力、自動保存、プロジェクト管理
- **重要ファイル**:
  - `file_io/yolo_format_handler.py`: YOLO形式の読み書き

#### 📊 monitoring/ - モニタリング層
- **役割**: システムの監視とデバッグ支援
- **主な機能**: パフォーマンス測定、ログ出力、エラー追跡
- **重要ファイル**:
  - `performance/performance_logger.py`: パフォーマンス記録

### 2. tests/ - テストコード

コードの品質を保証するためのテストが格納されています：

- **unit/**: 個々のモジュールをテスト
- **integration/**: 複数モジュールの連携をテスト
- **e2e/**: アプリケーション全体の動作をテスト

### 3. data/ - プロジェクトデータ

アノテーション作業で使用するデータ：

- **videos/**: 元の動画ファイル（4K推奨）
- **frames/**: 動画から抽出したフレーム画像
- **annotations/**: BBアノテーションデータ（YOLO形式）
- **backup/**: 自動バックアップ

### 4. config/ - 設定ファイル

アプリケーションの動作を制御する設定：

- **default_config.json**: デフォルト設定値
- **performance_targets.yaml**: 性能目標（50ms等）
- **layer_interfaces.yaml**: 層間の通信仕様

## 🔧 トラブルシューティング

### よくある問題

1. **アプリケーションが起動しない**
   - Python 3.8以上がインストールされているか確認
   - 仮想環境が有効化されているか確認
   - 必要なライブラリがインストールされているか確認

2. **フレーム切り替えが遅い**
   - メモリが十分にあるか確認（推奨64GB）
   - キャッシュ設定を確認
   - デバッグモードがOFFになっているか確認

3. **BBが表示されない**
   - アノテーションファイルが正しい形式か確認
   - 座標系の変換が正しく行われているか確認
